KARIGARAI - AGENTIC SERVICE BOOKING SYSTEM
PROBLEM STATEMENT
IN PAKISTAN, SKILLED WORKERS (PLUMBERS, ELECTRICIANS, AC TECHNICIANS, BEAUTICIANS, CARPENTERS) RELY ONLY ON
WHATSAPP AND PHONE CALLS TO FIND CUSTOMERS. THIS CAUSES DELAYS, NO AUTOMATION, AND DIFFICULTY FINDING NEARBY
WORKERS.
SOLUTION
KARIGARAI IS AN AI-POWERED AUTONOMOUS BOOKING SYSTEM BUILT ON GOOGLE ANTIGRAVITY THAT UNDERSTANDS
REQUESTS IN URDU, ENGLISH, AND PUNJABI, FINDS THE BEST PROVIDER AUTOMATICALLY, AND CONFIRMS BOOKING WITHOUT
ANY MANUAL STEPS.
HOW GOOGLE ANTIGRAVITY IS USED
- GOOGLE ANTIGRAVITY IS THE PRIMARY ORCHESTRATOR OF THE ENTIRE SYSTEM
- ALL AGENT WORKFLOWS ARE MANAGED THROUGH ANTIGRAVITY
- ANTIGRAVITY HANDLES: INTENT UNDERSTANDING, PROVIDER SEARCH, RANKING, DECISION MAKING, AND BOOKING EXECUTION
- CLAUDE WAS USED ONLY FOR GENERATING PROMPTS; ALL CODE AND AGENT LOGIC WAS BUILT AND EXECUTED BY
ANTIGRAVITY
SYSTEM ARCHITECTURE
USER INPUT → NLP AGENT → INTENT EXTRACTION → PROVIDER SEARCH AGENT → RANKING ALGORITHM → AI DECISION ENGINE
→ BOOKING AGENT → NOTIFICATION AGENT
AGENTS DEVELOPED
1. INTENT PARSER AGENT - UNDERSTANDS URDU/ENGLISH/PUNJABI INPUT
2. PROVIDER DISCOVERY AGENT - SEARCHES 50 PROVIDERS DATABASE
3. RANKING AGENT - RANKS BY DISTANCE, RATING, AVAILABILITY
4. DECISION AGENT - SELECTS BEST PROVIDER WITH REASONING
5. BOOKING AGENT - CREATES CONFIRMATION WITH UNIQUE KGR NUMBER
6. NOTIFICATION AGENT - SIMULATES SMS CONFIRMATION
APIS USED
- GOOGLE MAPS JAVASCRIPT API (REAL) - PROVIDER LOCATION DISPLAY
- GOOGLE MAPS EMBED API (REAL) - MAP VISUALIZATION
- WEB SPEECH API - VOICE INPUT IN 3 LANGUAGES
- MOCK PROVIDER DATABASE - 50 PROVIDERS ACROSS 10 LAHORE AREAS
